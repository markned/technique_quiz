# Общий рейтинг одиночной игры — проект, без реализации

Согласовано: общий рейтинг; ник без обязательной регистрации; один лучший результат на сохраняемый профиль. В этой итерации интерфейс рейтинга, хранение результатов и публичные API не добавляются.

## Предлагаемая первая версия

В меню одиночной игры появляется отдельный зачётный запуск. Свободная игра сохраняется. Сервер задаёт версию набора заданий, последовательность, время ответа и правила повторов. Сравниваются только игры с одинаковой версией правил и набора; произвольные пользовательские треки в общий зачёт не входят.

Сервер принимает отдельные ответы и сам считает итог. Готовое число очков от браузера не принимается. Подписанная сессия привязана к анонимному профилю и версии зачёта; повторные запросы идемпотентны, старые этапы отклоняются. При лимите бесплатных ресурсов новый зачёт временно недоступен, свободная игра остаётся доступной.

Профиль создаётся на устройстве, имеет секрет восстановления и редактируемый ник с ограничением длины. В таблице показываются ник, результат, дата и версия зачёта; IP и секреты не публикуются. Ник не удостоверяет личность: возможны новые профили, повторное прохождение и запоминание ответов. Это честно описывается как рейтинг игровых профилей, а не уникальных людей. Серверная проверка препятствует подмене результата, но не поиску ответов вне игры.

## Решения перед реализацией

Нужно отдельно согласовать: постоянный или меняющийся зачёт; длину сессии; разрешены ли повторы; порядок при равных результатах; восстановление профиля на другом устройстве; модерацию ников и срок хранения. До этого не создавать API и не выбирать окончательную схему хранения.

## Проверки будущей реализации

Поддельный результат, чужая сессия, повтор ответа, устаревший этап, превышение времени, восстановление соединения, смена версии набора, повторное завершение, параллельная запись лучшего результата и лимиты ресурсов. Правильные ответы не передаются до завершения соответствующего этапа; текущий клиентский каталог сам по себе не даёт такой гарантии.
